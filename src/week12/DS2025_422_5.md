步骤1：关键字分解  
每个关键字 K 可唯一分解为两个子关键字 K₁ 与 K₂，满足  
 K = K₁ × n + K₂  
其中 K₁、K₂ 均为整数且取值范围均为 [0, n)。  
 K₁ = ⌊K / n⌋ （高位子关键字）  
 K₂ = K mod n （低位子关键字）  
由于 K < n²，这种分解有效，且 K₁, K₂ ∈ [0, n−1]。

步骤2：应用基数排序  
将每个记录的关键字用二元组 (K₁, K₂) 表示。  
采用基数排序，按“低位到高位”顺序：  
1. 先按 K₂ 进行一次**稳定**计数排序；  
2. 再按 K₁ 进行一次**稳定**计数排序。  

每次计数排序的取值范围 r = n，时间复杂度 O(n + r) = O(n + n) = O(n)。  
子关键字总数 d = 2，故总时间复杂度  
 O(d × (n + r)) = O(2n) = O(n)。
