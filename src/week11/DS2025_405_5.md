# Quick Sort Unstability
## Initiate list: (2, 2', 1, 2")
| R₁  | R₂   | R₃  | R₄   | left | right |
| --- | ---- | --- | ---- | ---- | ----- |
| [2  | 2'   | 1   | 2"]  | 1    | 4     |
| [1   | 2"] | 2   | [2'] |      |       |
| 1   | 2"   | 2   | 2'   |      |       |

## Conclusion
As the example shows, the sequence of the three elements equaling to 2 in the sorted list is different from which in the predecessor, illustrating that quick sort is an unstable sorting algorithm.
